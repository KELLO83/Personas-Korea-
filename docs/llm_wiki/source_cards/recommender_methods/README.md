# Recommender Method Source Cards

This folder tracks external recommendation-system method families against the local Korean persona dataset shape.

## Local Compatibility Labels

- `High-priority`: local artifacts already fit the method and the method targets an active gap.
- `Benchmark`: feasible as an offline comparison, but not first priority.
- `Manual-review gated`: feasible technically, but promotion depends on human/qualitative review.
- `Defer`: needs missing feedback/session/temporal data or a larger export.
- `Reject`: mismatched to current data and not worth an experiment now.
